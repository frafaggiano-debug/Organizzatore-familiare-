# Casa Familiare

App familiare per menu, spesa, calendario, note e ricette.

## Funzioni
- Francesca: colazione, spuntino, pranzo, merenda, cena
- Alessio, Sara e Vera: pranzo e cena
- Navigazione tra settimane e copia della settimana precedente
- Spesa: dispensa, frutta e verdura, banco frigo, surgelati, farmaci, detersivi, macelleria, salumeria, pescheria
- Calendario: Francesca rosso, Alessio blu, Sara rosa, Vera verde, Famiglia viola
- Note e ricette
- Grafica responsive e PWA
- Salvataggio locale

## Pubblicazione GitHub Pages
1. Crea un repository, ad esempio `casa-familiare`.
2. Estrai lo ZIP e carica nel repository i file contenuti, non lo ZIP.
3. GitHub → Settings → Pages.
4. Deploy from a branch → `main` → `/ (root)` → Save.
5. Apri l'indirizzo Pages generato da GitHub.
6. Da smartphone puoi aggiungerlo alla schermata Home.

## Sincronizzazione
Questa prima versione salva i dati nel browser del dispositivo. La fase successiva sarà il collegamento a Supabase per condividere gli stessi dati tra i dispositivi della famiglia.
